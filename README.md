React News Finder

Este projeto é um aplicativo web feito em **React** que permite aos usuários **ver notícias em tempo real** com base em qualquer tema, utilizando uma **API de terceiros**. O usuário pode navegar pelas manchetes e explorar temas de forma prática e intuitiva.

Funcionalidades

✅ Visualizar as manchetes mais recentes com imagem, título, descrição e fonte  
✅ Interface responsiva e moderna  
✅ Modal de login e registro (frontend)
